The modular scales

A modular scale picks one base size (the body text) and one ratio, then multiplies: size = base × ration. H4 is one step up (n = 1), H3 is two steps, H2 three and H1 four. Body, emphasis and link text stay at the base (n = 0). Because every size comes from the same ratio, the hierarchy feels consistent instead of picked by eye. On phones each page lowers the root size, so the whole scale shrinks together and keeps the same proportions.

  • Perfect Fourth (1.333) for the Pixel Dungeon gives strong, dramatic jumps that suit a chunky pixel blackletter.
  • Major Third (1.25) for the Spellbook is gentler, like the steady rhythm of a printed book with only one typeface doing all the work.
  • Augmented Fourth (1.414, the square root of 2) for Insert Coin uses a 16px base, so H3 lands on 32px and H1 on 64px. Press Start 2P is built on an 8px grid and looks sharpest at multiples of 8.

Typefaces and requirements

  • Five typefaces from Google Fonts: Jacquard 24, Alegreya, Texturina, Press Start 2P and Pixelify Sans.
  • Variable fonts: Alegreya (weight 400–900 + italic), Texturina (weight 100–900, optical size 12–72 + italic) and Pixelify Sans (weight 400–700).
  • One-typeface hierarchy: The Spellbook uses only Texturina, getting contrast from its weight and optical-size axes, italics and color.
  • The experiment: The Pixel Dungeon pairs Jacquard 24, a pixel blackletter, with Alegreya, a calligraphic humanist serif. It isn't a pairing from a font list. I chose it because both come from broad-nib pen lettering: one rebuilt from square pixels, the other drawn with smooth curves. Together they feel like a retro dungeon crawler that grew up on fantasy novels.
  • Each page loads Bootstrap 5 and overrides its default heading, body, emphasis and link styles with custom CSS.
